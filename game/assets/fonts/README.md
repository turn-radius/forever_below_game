# Fonts

The plate's four faces, and Almendra Bold for the title lettering (`docs/rendering.md`, "Palette and UI"), downloaded from the Google Fonts repository (<https://github.com/google/fonts>, `ofl/`). Each is under the SIL Open Font License 1.1; its licence, with the copyright and any reserved font name, is the `*-OFL.txt` file beside it.

| File | Face | Use | Source |
|---|---|---|---|
| `Almendra-Regular.ttf` | Almendra, by Ana Sanfelippo | names, headings | `ofl/almendra` |
| `Almendra-Bold.ttf` | Almendra Bold, by Ana Sanfelippo (the same family and licence, `Almendra-OFL.txt`) | the title lettering | `ofl/almendra` |
| `AlegreyaSans-Regular.ttf`, `-Italic`, `-Medium` | Alegreya Sans, by Huerta Tipográfica | running text | `ofl/alegreyasans` |
| `IBMPlexMono-Regular.ttf`, `-Bold` | IBM Plex Mono, by IBM | numbers; Bold for values | `ofl/ibmplexmono` |
| `NotoSansRunic-Regular.ttf` | Noto Sans Runic, by the Noto Project | the seal's runes | `ofl/notosansrunic` |
